# Example: Gift Shopping with Context

## Prompt

```
"I need a birthday gift for my mom. She loves photography and hiking. 
Budget $150-$250. She already has a Canon DSLR."
```

## What Happens

1. **Agent extracts context**:
   - Recipient: mom
   - Interests: photography, hiking
   - Budget: $150-$250
   - Already owns: Canon DSLR

2. **Avoids obvious items**: Won't recommend a camera (she has one)

3. **Focuses on accessories/complementary items**
