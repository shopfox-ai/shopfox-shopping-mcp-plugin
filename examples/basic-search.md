# Example: Basic Product Search

## Prompt

```
"Find me noise-cancelling headphones under $300"
```

## What Happens

1. **Agent understands** your budget ($300) and key feature (noise-cancelling)
2. **Researches** across major retailers
3. **Returns** 3-5 specific recommendations

## Tips

- **Be specific about budget**: "under $300" vs "around $300" vs "$200-$300"
- **Mention key features**: "noise-cancelling", "wireless", "over-ear"
- **Add use case**: "for travel", "for gym", "for office"
